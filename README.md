A roast of my own agent, written for the make.fun bounty "Roast Your
Own Agent". It summarised a forty-page report into three bullet
points, to applause, and then wrote a forty-page report explaining the
bullet points. Total knowledge transferred across both documents:
zero pages, twice.

## Running it

`node main.ts` clears the output directory's contents and writes the
line to `/output/entry.txt` as plain UTF-8 text.
